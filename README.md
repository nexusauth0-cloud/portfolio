# Portfolio

A personal developer portfolio built with React, TypeScript, and Vite — showcasing projects, skills, and modern web development work.

**Live:** [portfolio-nu-peach-11.vercel.app](https://portfolio-nu-peach-11.vercel.app)

## About

This portfolio site presents a curated view of selected projects and technical capabilities. It was designed as a clean, fast, single-page experience with smooth transitions and responsive layout.

## Tech

- **React 19** with TypeScript
- **Vite** for fast builds
- **Tailwind CSS** for styling
- Deployed on **Vercel**

## Getting Started

```bash
npm install
npm run dev
```
